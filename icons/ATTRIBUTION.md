# Icons

## UI icons (popup, sidebar, reader, settings)

Inline SVG paths are generated from **[Lucide Icons](https://lucide.dev/)** (ISC License).

To refresh after adding icon names in `scripts/generate-icons.mjs`:

```bash
npm install lucide sharp
node scripts/generate-icons.mjs
```

## Extension toolbar icons (`icon16.png` … `icon128.png`)

Rasterized from `icon-source.svg`, which uses the Lucide `scan-search` glyph on a brand background.

Lucide license: https://github.com/lucide-icons/lucide/blob/main/LICENSE
